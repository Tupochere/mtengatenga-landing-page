# Mtengatenga Museum AR Landing Page

The promotional and instructional landing page for the Mtengatenga Museum AR app.

## Language

**Admin Portal**:
The web application used to manage artifacts, rooms, and analytics for the museum.
_Avoid_: Web App, Admin Dashboard, Web Dashboard, Management Portal

**QR Test Pack**:
A downloadable ZIP file containing sample QR codes used to test the AR scanning functionality without being in the physical museum.
_Avoid_: QR test assets, QR images
